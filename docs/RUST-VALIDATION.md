## 配布

Python版のコード・依存設定・旧テスト・比較スクリプトを削除し、`launch.bat`もRust版の起動へ変更しました。削除後にRustの52テストが再度成功しています。アイコンは白基調の画像・選択枠マークを追加しました。アプリ本体のWindows配色追従は維持しています。

アイコン入りrelease EXEを実際に起動し、タイトルバーへの表示と正常終了を確認しました。EXEから抽出したアイコンの白地、およびビルド成果物・配布EXE・ZIP内EXEのハッシュ一致も確認しています。ZIP内にPythonコードはありません。

`build-rust.ps1` でrelease EXEと依存ライセンスを含むZIPを作成します。MSVC CRTを静的リンクし、dumpbinで確認した直接DLL依存はWindowsのシステムDLLだけでした。Python/OpenCVのDLL依存はありません。

生成ZIPを別フォルダーに展開し、PATHをWindowsとSystem32だけに制限してEXEを起動し、1,818枚の保存済みプロジェクトの一覧描画が正常終了することを確認しました。展開したEXE・配布元EXE・ビルド成果物のSHA256は一致しました。同一PCのGPUドライバーなどは使っているため、開発環境のない別PCでの検証とは区別します。
