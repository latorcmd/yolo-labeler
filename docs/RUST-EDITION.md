# YOLO Labeler — AntiWebUI / Rust

Windows x64向けのRust版です。Python、OpenCV、モデル取得、外部サーバーは不要です。GUIはAntiWebUI、画像処理はimage/imageprocを使用しています。

## 起動と配色

配布ZIPを展開して `yolo-labeler.exe` を起動します。リポジトリでは `launch-rust.bat` を使用します。Windowsの「既定のアプリモード」に合わせてライト／ダークを選び、起動中の変更にも約1秒以内に追従します。設定が読めない場合はライトです。元画像の色は変わりません。

ソースからビルドする場合は、Rust stable MSVCとVisual Studio C++ Build Toolsを導入し、`./build-rust.ps1` を実行します。依存版はCargo.lock、AntiWebUIとwgpu forkはCargo.tomlのコミットに固定しています。成果物は `dist/yolo-labeler-windows-x64.zip`。MSVCランタイムを静的リンクする設定を使用します。

## データセット

「新規」で画像フォルダーを選び、必要なら別のラベルフォルダーを指定します。classes.txtがなければクラス名を1行ずつ入力します。先頭行がID 0です。

プロジェクト形式は **.ylp2**。同名の **.ylp2.assets** フォルダーに画像・ラベルのコピーを保存します。プロジェクトを移動するときは、このファイルとフォルダーを同じ名前の組で移動してください。元画像・元TXTは書き換えません。旧.ylprojectの読み込み・変換はありません。

「画像を追加」「フォルダー追加」で追加入力できます。同名の異なる画像も保持し、同じ元パスの再追加はスキップします。変更した元ファイルの同じパスを再追加しても再読込しません。異なる追加元のclasses.txtは現在と同じ順序・名称が必要です。追加元にクラス一覧がない場合は現在のID順として扱います。

## 選別・編集

- 10枚一覧をクリック、または1〜0で除外予定を選び、Enterまたは「ページ確定」で判断を保存します。
- 未承認候補、ラベル不正・不足、枠なしの画像は一覧確定だけでは採用できません。
- ダブルクリックまたは「枠を編集」で編集します。Vは選択、Wは描画、Pはパン。ホイールでズームし、四隅でサイズ変更します。
- 対象がない画像は明示的に確認して保存できますが、提出ZIPでは枠0個をブロックします。
- Ctrl+Sは保存、Ctrl+ZまたはUndoは判断・枠編集を取り消します。起動中最大40操作で、画像追加自体と再起動後Undoは対象外です。
- フィルター・並び順・検索・ページを保存して再開します。配色変更でも編集中の内容は保持します。

## 半自動・品質検査

「半自動の設定」から、大津法（しきい値空欄）または手動しきい値、成分条件、余白を設定します。固定クラス、またはstart,end,class_idの範囲CSVを選び、先頭画像のプレビュー後に一括候補を生成できます。基本は1画像1対象です。確認済み、採用・除外の画像は再生成から保護します。

候補は編集画面で承認または破棄してから保存します。外部YOLO候補は対応するclasses.txtが必要です。複数の追加元がある場合は対象の追加元の画像を1枚選択してから読み込みます。候補フォルダーは元の相対パス構成へ対応させてください。basenameだけでは照合しません。

暗さ・ぼけ・白飛び・対象の小ささは確認候補です。その指標だけで自動除外しません。「破損・重複を除外」は、検査した未確認の破損画像、またはラベルが同じ完全重複のみを候補にします。元ファイルは保持します。画像・ラベル編集後は再検査してください。

画像処理方式はRust版として識別し、Python版と品質数値の完全一致は保証しません。基準値や指紋が異なる古い結果では自動除外しません。

## 保存・復旧・出力

操作後はプロジェクトを保存し、前回内容を.ylp2.bakへ残します。追加中はassets内の取込記録を使い、コピー公開後に保存できなかった場合は再読込時に復旧します。未保存の表示が出た場合は閉じずに保存をやり直してください。

出力は移行前と同じV-Training Detection ZIP条件です。人が確認した採用画像101枚以上、各クラスの採用枠、200,000,000bytes以下を要求します。ZIP直下にclasses.txt、v-training.config、連番のRGB JPEG/TXTを置き、元画像hash・完成ZIP・CRCを再検査します。元名対応はZIP外のreport.jsonに保存します。同名ZIP・レポートは上書きしません。アップロードは行いません。

## 開発・検証

```powershell
cargo test --workspace --locked
cargo run --release -p labeler-core --example qa -- prepare IMAGE_FOLDER OUTPUT.ylp2
```

開発用の `--project PATH.ylp2` で保存済みデータを開けます。`--qa-screen OUTPUT.png --project PATH.ylp2 --dark --scale 1.5 --edit` はウィンドウを開かない画面検証用です。通常起動の配色は常にWindowsに従います。

実測値と検証済み・未確認の区別は、リポジトリの `docs/RUST-VALIDATION.md` に記録します。

アプリアイコンは画像と選択枠を組み合わせた独自の図形です。16〜256pxのICOをEXEへ組み込み、Windowsのウィンドウとタスクバーにも設定します。再生成には開発用の `tools/create-icon.ps1` を使います。ビルド時にはWindows SDKのリソースコンパイラーが必要です。
